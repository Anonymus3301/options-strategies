Strategy Explained

Construction: no position here — the whole-chain put/call ratio (every live expiry combined) is tracked against its own recent range in this browser's localStorage.

Market view: a contrarian sentiment signal — extremely high PCR (the crowd very bearish or heavily hedged) sometimes precedes a bounce; extremely low PCR (the crowd very bullish or complacent) sometimes precedes a pullback.

Why shown: as one input among many for gauging positioning extremes, not a standalone timing signal.

Max profit / max loss: not applicable — no position is constructed or scored on this page.

Key risk / caveat: flagged explicitly as weak and noisy; PCR extremes can persist for a long time in a trending market, so using it alone as a timing tool has a poor track record.

Not financial advice. Put/call ratio as a contrarian indicator is a widely-cited but weak, noisy signal — extreme readings can persist for a long time without any reversal, and a lot of put OI/volume is routine hedging rather than speculative bearish bets. This whole-chain PCR combines every live expiry, so it can mask very different positioning at different tenors (check the main ladder's per- expiry PCR stat for that).
