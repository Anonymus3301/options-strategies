Put/call ratio as a contrarian indicator is a widely-cited but weak, noisy signal — extreme readings can persist for a long time without any reversal, and a lot of put OI/volume is routine hedging rather than speculative bearish bets. This whole-chain PCR combines every live expiry, so it can mask very different positioning at different tenors (check the main ladder's per- expiry PCR stat for that).
