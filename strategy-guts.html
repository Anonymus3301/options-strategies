Strategy Explained

Construction: buy an ITM call below spot and an ITM put above spot — both legs start in-the-money.

Market view: identical payoff shape to a Long Strangle at expiry, just re-centered — still a pure bet on a big move.

Why trade it: because both options are ITM, their combined intrinsic value between the two strikes sums to a constant, guaranteed amount regardless of exactly where price lands in that range — you're effectively pre-paying for value you're guaranteed to get back.

Max loss: total cost minus the locked-in value (the true premium at risk), if price stays between the strikes. Max profit: unlimited above, large below — exactly like a strangle built at the same two strikes.

Key risk: by put-call parity, Guts should cost about the same as an equivalent OTM strangle plus the locked-in value — always compare the "cost above locked-in value" figure to an OTM strangle's cost, not the sticker price, before assuming this is worse.
